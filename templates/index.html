FIELD NOTE / CHOOSE THE TOOL

When not to use HTMX

Use HTMX when the server owns the state and an HTML response is the natural result. Choose a client-side tool when the interaction is primarily local, continuous, or offline.

Prefer client JavaScript

For canvas, drag-and-drop, games, rich editors, audio work, or high-frequency interactions that must respond without a network round trip.

Prefer a client app

For large client-owned state graphs, complex offline workflows, or interfaces where most screens are calculated from local data.

Prefer plain HTML

For simple navigation, static content, and forms that do not need partial updates. Do not add HTMX just because it is available.

Rule of thumbKeep the source of truth close to the state that changes.
